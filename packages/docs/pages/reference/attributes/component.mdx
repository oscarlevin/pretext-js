# `component`

The `component` attribute is used to assign _version_ to a particular part of your document. When compiling,
you (the publisher) can choose which _component_s to include in the final output.

## Examples

 ```ptx-example
<FRAGMENT parents="p">
    Since the publication file the builds this example uses the <c>examples</c> component, we will see <em component="examples">this</em> and not <em component="non-examples">that</em>.
</FRAGMENT>
```
